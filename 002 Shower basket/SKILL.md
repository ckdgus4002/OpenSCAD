# 샤워 바구니 (Parametric Honeycomb Shower Basket)

- 파일: `/Users/lch/OpenSCAD/002 Shower basket/shower_basket.scad` (맥 로컬, 단일 파일)
- 의존성: BOSL2 (https://github.com/BelfrySCAD/BOSL2)

## 편집 규칙

- 이 모델은 Claude 로만 수정한다. `.scad` 에는 설명 주석을 달지 않고, 근거/의도/주의사항은 이 스킬에 기록한다.
- `/* [탭 이름] */`, `/* [Hidden] */` 은 OpenSCAD Customizer 탭 문법이므로 유지한다.

## 테두리 곡률 (사용자 결정)

- 바깥 모서리 곡률은 R10: 세로 모서리 `corner_r`, 바닥 모서리 `bot_r`.
- 윗면 테두리는 `bead_r = wall / 2` (벽 두께 전체를 덮는 반원, 벽 4mm 기준 2R)이며, 벽 두께 안에서 가능한 최대 곡률이다.
- `bead_r` 를 `wall / 2` 보다 키우면 테두리가 벽 안팎으로 튀어나온 두꺼운 원통이 된다. 사용자가 이 모양은 잘못됐다고 했으므로 키우지 않는다. 윗면을 더 둥글게 해 달라는 요청이 오면 이 한계를 먼저 설명한다.

## 좌표계

- 몸통 모듈(`wall_mesh_*`, `floor_mesh`, `handle_*`, `bottom_edge_mask`, `top_bead`)은 "몸통 바닥 중심"이 원점인 좌표계 기준이다.
- `basket_feet` 만 `up(fh)` 바깥에서 호출되므로 바닥면(z=0) 기준이다.

## 파라미터

- `height`: 몸통 높이(Z). 받침대는 제외 (받침대 포함 총 높이는 `total_h`).
- `thickness`: 기본 두께. 벽(`wall`), 바닥(`floor_th`), 벌집 살(`hex_web`)이 모두 이 값을 따르므로 두께는 여기만 바꾼다.
- `hex_size`: 육각 구멍 크기 = 마주보는 면 사이 거리.
- `edge_r`: 손잡이 구멍 모서리 라운드 반경 (벽 양쪽 면).
- `handle_margin`: 손잡이 구멍 둘레에 벌집을 뚫지 않고 남길 여유. 클수록 손잡이 테두리가 두꺼워진다.
- `feet_h`: 엄지손가락이 들어갈 높이.
- `feet_r = hex_size / 2`: 육각 셀에 딱 내접하는 반경.
- `bead_r = wall / 2`: 상단 비드 반경. wall/2 = 완전한 반원 마감.

## 파생값

- `R`: 육각 외접원 반경
- `Rp`: 살 두께를 포함한 피치용 반경
- `dxg`, `dyg`: 육각 격자 가로 피치(한 칸), 세로 피치(한 줄)
- `hz`: 손잡이 중심 높이
- `jmax`: 실제로 존재하는 육각 줄의 최대 번호. 두께에 따라 달라진다.

## 받침대 배치 (`foot_layout`)

- 형식: `[ 육각 줄 j, [ 오른쪽 절반의 가로 칸 i 목록 ] ]`
- `j`: 0 = 정중앙 줄, + 위쪽(+Y) / - 아래쪽. 두께를 바꾸면 격자가 변해 줄 수가 줄 수 있고, 없는 줄은 가장 바깥 줄로 자동 보정(클램프)된다.
- `i`: 오른쪽 방향 칸 번호. 오른쪽 절반만 지정하면 ±로 미러링되어 왼쪽이 자동 배치되므로, 두께가 바뀌어도 항상 좌우 대칭이다.
- 짝수 줄은 i=0 이 정중앙, 홀수 줄은 i=0 이 중앙에서 반 칸 오른쪽. 짝수 줄에 0 을 넣으면 정중앙에 1개가 생긴다.
- 주의: `i` 가 줄 범위를 벗어나면 조용히 엉뚱한 칸으로 붙는다. 이를 잡으려고 `foot_err` 로 "!! 경고" 를 echo 하므로 렌더 로그를 확인한다.

## 설계 의도

- 육각 격자: 꼭짓점이 위를 향하게 배치해 벽 구멍을 서포트 없이 출력한다. `hex_centers` 는 중심이 영역 안에 있는 셀만 반환해 가장자리 얇은 조각을 막는다.
- `hexcut`: 격자 중심이 경계 바로 밖(R 이내)에 있어도 포함시켜, 셀 일부가 cuboid 안으로 들어오면 그만큼 뚫리게 한다. 테두리에서 "반쪽 셀"이 통째로 막히는 것 방지.
- `wall_mesh_fb`, `wall_mesh_lr`: 모서리 살(`corner_r`) 경계에 육각이 반쪽만 걸치면 뚫리지 않고 막히므로, 격자 한 칸(`dxg`)만큼 더 넓혀 그 반쪽 셀까지 확실히 뚫는다.
- `floor_mesh`: 받침대가 놓이는 육각은 뚫지 않아 통짜 패드가 된다.
- `handle_keepout`: 손잡이 구멍을 `handle_margin` 만큼 부풀린 캡슐 하나뿐이라, 손잡이 좌/우/위쪽도 벌집이 그대로 뚫린다.
- `handle_cut`: 벽 두께 구간에서 양쪽 면으로 벌어지는 필렛으로 구멍 모서리를 둥글게 하고, 벽 바깥으로 연장해 확실히 관통시킨다.
- `top_bead`: 경로 코너 반경 `max(corner_r - wall / 2, bead_r + wall / 2)`. `bead_r = wall / 2` 이면 첫 항이 선택되어 벽 중심선을 따르고, 비드 바깥 코너가 `corner_r` 와 맞는다. 둘째 항은 `bead_r` 를 키웠을 때 코너 안쪽 자기교차를 막는 용도.
- `basket_feet`: 채워진 육각 셀에 내접하는 원기둥이며, 아래로 갈수록 좁아져 오버행이 없다.
